# Starz Promosyon

A simple Telegram bot that gives users random ideas and recommendations.

## Setup

1. Create the bot with Telegram's BotFather and copy the bot token.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Set the token as an environment variable:
   ```bash
   export BOT_TOKEN="YOUR_BOT_TOKEN"
   ```
4. Run:
   ```bash
   python bot.py
   ```

The bot does not store a token in the repository.
